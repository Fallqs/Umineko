## 一、六轩岛公开地图

```
                    [海]
                     │
                [港口·船坞]
                 /      \
           [灯塔]      [沙滩]
               \        /
              [玫瑰园·大门]
                     │
    [本馆] —— [中庭] —— [别馆(宾馆)]
   /   |   \          |            \
[书房] [餐厅] [客房] [神社]       [庭院]
              |       |             |
         [中庭花园] [祭具殿]     [仓库]
              |
         [镇守之森]
              |
         [悬崖/海蚀洞]
```

### 地图说明

- **本馆**：家族成员主要居住与活动场所。一层有大厅、餐厅、厨房；二层有书房、客房；三层有客房。
- **别馆**：佣人与外来工作人员居住。一层是公共区域，二层是卧室。
- **神社**：位于"猫背"山脊南坡，有鸟居、祭坛、方尖碑和祭具殿。
- **镇守之森**：神社后方的茂密森林，有石阶路和悬崖。
- **玫瑰园**：本馆正门前的花园，有青铜雕像。
- **港口**：岛屿南面，有栈桥和废弃灯塔。

### 家族关系说明

**长房（藏臼一脉）**：
- 藏臼与夏妃是夫妻，但关系冷淡，分居不同卧室。
- 朱志香是他们的独生女，19岁，高中生。

**次房（留弗夫一脉）**：
- 留弗夫与雾江是再婚夫妻。留弗夫的前妻明日梦（战人与让治的生母）已于1980年去世。
- 让治是长子，20岁，经营服装店。
- 战人是次子，16岁，6年前因母亲去世与家族决裂，今年首次归来。

**幼女（楼座一脉）**：
- 楼座是单亲母亲，真里亚9岁。真里亚的父亲身份不明（楼座从未说明）。

**入赘**：
- 秀吉是让治的父亲，入赘右代宫家。

## 三、佣人与工作人员

```
[纱音]——女仆，约20岁，在岛上工作10年
   │
[嘉音]——佣人，约16岁，在岛上工作10年，负责园艺
   │
[熊泽]——老女仆，在岛上工作多年
   │
[乡田]——厨师，在岛上工作多年
   │
[南条]——医师，金藏的私人医师，每年家族会议随行
```

### 佣人关系说明

- 纱音与嘉音都是年轻佣人，在岛上工作了约10年。他们分别负责接待与园艺。
- 熊泽是老女仆，知道很多岛上的旧事。
- 乡田是厨师，对自己的料理很自豪。
- 南条医师每年随家族会议前来，负责金藏的健康管理。
