# 《海猫鸣泣之时：六轩岛黄昏》联机客户端

> 基于 kimi-code-cli 的多进程剧本杀联机游玩系统

## 一、系统概述

本客户端利用 kimi-code-cli 的 **AGENTS.md 权限系统** 和 **审批流程** 实现了一个分布式剧本杀游玩框架：

- **每个角色 = 一个独立进程**：玩家在自己的设备上启动 kimi-code-cli，工作目录指向对应角色的文件夹
- **文档权限隔离**：角色进程通过 AGENTS.md 只能看到角色自身的文档，无法偷看GM文档或其他角色的隐藏层
- **AI GM协程**：每个角色进程中的原生AI助手负责本地规则判定（行动点追踪、信息条目管理）
- **审批流程映射**：kimi-code-cli的approval runtime被用于游戏内选项（解锁隐藏层、宣告死亡、使用红字等）
- **消息路由器**：进程间通过文件系统或WebSocket交换消息，实现跨设备联机

## 三、快速开始

### 3.1 环境要求

- **Python 3.8+**
- **kimi-code-cli**（已安装并配置好）
- 可选：`pip install websockets`（仅server模式需要）

### 3.2 单机模式（同一台电脑）

```powershell
# 1. 进入客户端目录
cd repo/umi_client

# 2. 启动消息路由器（新终端）
python scripts/router.py --mode local

# 3. 启动GM进程（新终端）
cd gm
kimi

# 4. 启动玩家进程（每个角色一个终端）
cd ../roles/右代宫战人
kimi

# 另一个终端
cd ../roles/右代宫朱志香
kimi

# ...以此类推
```

### 3.3 多设备联机

**方案A：共享文件夹（最简单）**

使用 Dropbox、Syncthing、Resilio Sync 或 NAS 共享 `shared/` 目录：

1. GM设备：启动路由器 `python scripts/router.py --mode local`
2. 所有设备：将 `shared/` 目录同步
3. 各设备：启动对应角色的 kimi 进程

**方案B：WebSocket服务器**

1. GM设备启动中心服务器：
```powershell
python scripts/router.py --mode server --host 0.0.0.0 --port 8765
```

2. 各设备上的角色进程需要配置WebSocket客户端（需后续开发，当前版本仅支持文件系统）

> **当前版本主要支持方案A（共享文件夹）**，WebSocket完整客户端将在后续版本实现。

### 3.4 使用启动脚本（Windows）

```powershell
# 启动路由器和提示
.\scripts\start-game.ps1 -Mode local

# 启动特定角色（在新终端中）
.\scripts\start-game.ps1 -Role 战人
```

## 四、游戏流程

### 4.1 准备阶段

1. GM使用 `game_master.py` 初始化游戏状态：
```powershell
python scripts/game_master.py --init
```

2. GM查看当前状态：
```powershell
python scripts/game_master.py --status
```

3. 所有玩家启动各自角色进程，确认连接

4. **启动NPC进程**（贝阿朵莉切、真里亚等）：
```powershell
# 贝阿朵莉切（NPC）
cd roles/贝阿朵莉切
kimi --hide-thinking --agent-mode --agent-pipe ../shared/inbox/贝阿朵莉切/agent_pipe.jsonl

# 真里亚（NPC）
cd roles/右代宫真里亚
kimi --hide-thinking --agent-mode --agent-pipe ../shared/inbox/右代宫真里亚/agent_pipe.jsonl
```

NPC进程使用 `--hide-thinking` 隐藏AI思考过程，`--agent-mode` 从pipe文件读取输入而非键盘。

### 4.2 回合推进

GM使用辅助控制台推进游戏：

```powershell
# 推进到下一阶段（MORNING → INVESTIGATION → ...）
python scripts/game_master.py --next-phase

# 生成分组方案（自动遵循纱音/嘉音隔离等规则）
python scripts/game_master.py --group

# 手动分组
python scripts/game_master.py --group-manual "本馆:战人,藏臼;别馆:让治,朱志香;神社:纱音,真里亚"
```

### 4.3 死亡与切换

```powershell
# 宣告角色死亡（自动发送SWITCH消息）
python scripts/game_master.py --kill 右代宫朱志香 --kill-cause "密室哮喘发作"

# 发放信息条目
python scripts/game_master.py --info 右代宫战人,C-18 --info-content "金藏的真正死因是心脏麻痹" --info-score 4

# 广播消息
python scripts/game_master.py --broadcast "暴风雨即将来临..." --broadcast-type system
```

角色收到 `SWITCH` 消息后：
1. AI助手向玩家宣告死亡和得分
2. 玩家关闭当前进程
3. 玩家以新角色的工作目录重启 kimi-code-cli
4. 新进程自动继承已收集的信息条目

### 4.4 审批流程

以下操作会触发 kimi-code-cli 的 approval runtime，需要GM确认：

- 角色调查可能触及核心隐藏层的地点
- 战人使用验尸/逻辑推演（消耗行动点）
- GM执行强制击杀
- 核心隐藏层解锁
- 红字/金字使用
- 失控强制行动

## 六、AI助手（GM协程）的工作方式

每个角色进程中的AI助手扮演"GM协程"角色：

### 6.1 对玩家的帮助
- 以角色视角回答问题（"作为朱志香，你会怎么做？"）
- 提醒角色的已知信息和性格特点
- 帮助理解规则和机制

### 6.2 规则执行
- 追踪每日行动点（战人：2点/日）
- 追踪特殊能力使用次数（朱志香：大声疾呼1次/日）
- 验证行动合法性（如：只有战人能验尸）
- 追踪已收集的信息条目

### 6.3 消息处理
- 从 `shared/inbox/{角色名}/` 读取新消息
- 将玩家的发言/行动写入 `shared/inbox/outbox/`
- 区分同场景发言(say)、私聊(whisper)、行动(action)

### 6.4 安全红线
- **绝不**访问 `gm/` 目录
- **绝不**查看其他角色的文件夹
- **绝不**在解锁前透露核心隐藏层
- **绝不**代替GM执行死亡宣告

## 七、自定义与扩展

### 7.1 添加新角色

1. 复制模板：`cp -r roles/_TEMPLATE roles/新角色名`
2. 修改 `roles/新角色名/AGENTS.md` 中的角色信息
3. 在 `scripts/router.py` 的 `ALL_CHARACTERS` 列表中添加角色名
4. 在 `scripts/game_master.py` 的 `CHARACTER_CHAINS` 中添加角色链

### 7.2 修改规则

- 修改 `shared/rules.md` 影响所有角色的公开规则
- 修改 `gm/AGENTS.md` 影响GM代理行为
- 修改角色目录下的 `AGENTS.md` 影响单个角色的AI协程

### 7.3 联机扩展

当前基于文件系统的方案适合：
- 同一台电脑
- 局域网共享文件夹（SMB/NFS）
- 云同步文件夹（Dropbox、Syncthing）

如需真正的网络联机：
1. 启动 `router.py --mode server`
2. 为每个角色进程添加WebSocket客户端代码
3. 角色进程通过WebSocket连接中心服务器收发消息

## 九、设计理念

> *「没有爱，就看不见。」*
>
> 这个客户端的设计理念是：**让AI扮演协程而非替代人类**。
>
> - AI负责繁琐的规则计算和状态追踪
> - 人类GM保留创意和最终决策权
> - 玩家获得AI的角色扮演辅助，但核心体验仍是人与人的推理对决
> - 文档权限系统模拟了"信息不对称"这一剧本杀的核心乐趣

## 附录：六轩岛风物志（公开版）

> *「风是记忆的载体，潮是时间的低语。」*

六轩岛位于伊豆诸岛南端，面积约三平方公里，中央有一座海拔287米的山脊，被当地人称为"猫背"。岛的北面是陡峭的悬崖与海蚀洞，南面有唯一的登陆沙滩与港口。

### 主要场所

- **本馆**：西洋式建筑，灰色花岗岩外墙，三层高。大厅挑高六米，天花板绘有魔女壁画；餐厅有十三孔烛台；金藏的书房位于二层，装有三重锁。
- **别馆（宾馆）**：日式木造结构，佣人与外来工作人员居所。嘉音和纱音的房间在二层西端。
- **玫瑰园**：本馆正门前约两千平方米的花园，种植红、白、深紫玫瑰。中央有一座青铜雕像，底座刻着："致吾爱，贝阿朵莉切。她从未存在，因此永远不会消失。"
- **贝阿朵莉切神社**：本馆东北方约三百米处，朱红色鸟居后有石砌圆形祭坛和黑色方尖碑。旁有青铜门的"祭具殿"。
- **镇守之森**：神社后方的茂密森林，以黑松与杉木为主。林间有昔日渔民修建的石阶路，部分已损坏。森林深处据说有一座无碑的坟墓，悬崖下面是海蚀洞。
- **港口**：岛屿南面的小型海湾，有水泥栈桥和废弃灯塔。唯一交通工具是柴油船"缘寿丸"。

### 季节与天象

- **十月满月**：10月6日农历八月十五。
- **台风"艾普西隆"**：1986年10月5日至7日影响伊豆诸岛。
- **黑玫瑰（贝阿朵之泪）**：仅在十月第一周绽放，花瓣边缘金黄，中心血红。
