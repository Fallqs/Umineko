# GM 专用：信息条目注册表

> **绝密文件 — 仅供 GM 查阅**
> 本表是 Orchestrator 自动计分的唯一依据。
> GM 通过 `request_info_unlock` / `check_info` 等动作查询或修改本表中的条目。

---

## 使用说明

1. **ID 规范**
   - `P-<角色>-XX`：公开条目（1 分）
   - `S-<角色>-XX`：半隐藏条目（2 分）
   - `C-XX`：核心隐藏条目（4 分）
2. **解锁方式**
   - 当玩家在游戏中满足条件时，GM 通过 ORCHESTRATION_REQUEST 向 orchestrator 发起 `request_info_unlock`。
   - Orchestrator 会根据本注册表自动计算分数。
3. **GM 主观分**
   - 与规则计分独立，通过 `gm_bonus` 动作记录，不在本表中。

## 附录：GM 可调用 Orchestrator 动作速查

GM 通过回复中的 `【ORCHESTRATION_REQUEST】` 块调用 orchestrator。以下是与信息条目、计分、角色历史相关的常用动作：

### 信息条目

```
【ORCHESTRATION_REQUEST】
action: request_info_unlock
params: {"target": "右代宫战人", "info": "C-17"}
【/ORCHESTRATION_REQUEST】
```
- 为指定角色解锁信息条目。`info` 必须是本表中的 ID。
- Orchestrator 会自动拒绝元游戏、过于宽泛或长度小于 8 字符的请求。

```
【ORCHESTRATION_REQUEST】
action: check_info
params: {"target_role": "右代宫战人", "info_id": "C-17"}
【/ORCHESTRATION_REQUEST】
```
- 查询某角色是否已解锁指定条目。

### 计分与角色历史

```
【ORCHESTRATION_REQUEST】
action: get_score
params: {"seat_id": "P1"}
【/ORCHESTRATION_REQUEST】
```
- 查询某个 seat 的当前累计得分（规则分 + GM主观分）。
- 不传 `seat_id` 则默认查询当前 seat。

```
【ORCHESTRATION_REQUEST】
action: get_player_history
params: {"seat_id": "P1"}
【/ORCHESTRATION_REQUEST】
```
- 查询某个 seat 扮演过的所有角色（按顺序）。

```
【ORCHESTRATION_REQUEST】
action: gm_bonus
params: {"seat_id": "P1", "points": 3, "reason": "触发嘉音挥剑救纱音 if 线"}
【/ORCHESTRATION_REQUEST】
```
- 为指定 seat 增加 GM 主观分。与规则计分独立结算，可正可负。

### 其他常用动作

```
action: spend_action_point      params: {"target": "右代宫战人", "amount": 1}
action: refund_action_point     params: {"target": "右代宫战人", "amount": 1}
action: use_ability             params: {"target": "右代宫战人", "ability": "验尸"}
action: check_group_valid       params: {"character": "嘉音", "restricted_with": "纱音"}
action: get_state               params: {}
action: send_message            params: {"target_role": "右代宫朱志香", "message": "..."}
```
