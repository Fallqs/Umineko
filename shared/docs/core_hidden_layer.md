# GM专用：核心隐藏层汇总与解锁条件

> **绝密文件 — 仅供GM查阅**
> **严禁向玩家展示本文件的任何内容**

---

## 使用说明

1. 本文件记载所有角色（含备用角色）的核心隐藏层内容。
2. 每个核心隐藏层都有对应的**解锁条件**。只有当玩家在游戏中满足该条件时，GM才能向该玩家揭示对应内容。
3. 揭示方式：GM将对应内容口述或写在纸条上交给玩家，或在角色卡上撕开封条。
4. **绝对禁止**在游戏开始前让玩家阅读核心隐藏层。

## 三、GM向玩家揭示核心隐藏层的操作指南

### 3.1 揭示方式

**方式一：口述告知**
- GM将玩家叫到一旁，口述核心隐藏层的内容。
- 适用于简单的隐藏条目（如单条信息）。

**方式二：纸条传递**
- GM将隐藏内容写在纸条上，折叠后交给玩家。
- 适用于复杂的隐藏条目（如包含多条信息）。

**方式三：封条撕除**
- GM在玩家的角色卡上找到对应的核心隐藏层区域，亲手撕开封条或划开密封线。
- 最具仪式感的方式，推荐用于关键隐藏条目的揭示。

### 3.2 揭示时机

**立即揭示**：当玩家通过调查/对话直接触达隐藏信息时，GM应立即揭示。例如：
- 朱志香搜索钢琴凳发现钥匙→立即揭示C-05
- 战人调查仓库发现刻字→立即揭示C-17

**延迟揭示**：当玩家触发了条件，但GM希望制造悬念时，可以延迟到当晚或次日早晨揭示。例如：
- 雾江发现胶囊被替换→GM可以延迟到雾江试图使用时才揭示

**终局揭示**：某些隐藏条目只在最终对决或死亡时揭示。例如：
- 所有触发死亡条件在死亡时由GM宣告
- 战人的隐藏结局条件在终局时判定

### 3.3 记录要求

每次揭示核心隐藏层时，GM应在**泄露记录表**上标注：
- 日期
- 被揭示角色
- 被揭示条目
- 触发条件的玩家（如果是其他玩家触发的，计入对抗机制的泄露次数）
