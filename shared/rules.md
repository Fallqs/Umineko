# 《海猫鸣泣之时：六轩岛黄昏》公开规则

> *「欢迎来到六轩岛。」*
> *「在这里，一切真相都隐藏在玫瑰与雾气之下。」*

## 一、背景故事

1986年10月4日，右代宫家一年一度的家族会议在私人岛屿"六轩岛"召开。家主右代宫金藏召集了分散在各地的家族成员，宣布这将是一次"特别的家族会议"。

然而，金藏未出席晚宴。深夜，他的尸体在书房中被发现——周围有神秘的魔法阵与蜡烛，房门从内部上锁。与此同时，一位自称"贝阿朵莉切"的神秘人物出现在岛上，她声称自己是"黄金魔女"，而这一切只是"游戏"的开始。

**你，是右代宫家的一员（或岛上的佣人）。**
**你将在接下来的七天中，面对死亡、谜团与魔女的挑战。**

## 二、核心规则

### 2.1 你的身份卡

每位玩家都会收到一张**身份卡**，上面记载着你所扮演角色的信息。身份卡分为三层：

| 层级 | 颜色标记 | 说明 |
|------|---------|------|
| **公开层** | 白色 | 所有玩家都知道的基础信息（姓名、年龄、身份、外貌等） |
| **半隐藏层** | 黄色 | 只有你自己知道的秘密（动机、关系、部分往事）。**建议对其他玩家保密**，但你可以选择性透露 |
| **核心隐藏层** | 红色 | 被密封的深层秘密。**绝对不可自行拆阅**！只有满足特定条件后，由GM开启 |

**重要**：你的核心隐藏层中可能包含"死亡触发条件"——某些特定情境下你的角色会自动死亡。你**不会预先知道**这些条件是什么。

### 2.2 信息条目系统

六轩岛上的一切情报都被量化为**"信息条目"**。你通过调查、对话、观察来收集它们。

| 条目类型 | 分值 | 获取难度 |
|---------|------|---------|
| 公开条目 | 1分 | 极易获得，基础观察即可 |
| 半隐藏条目 | 2分 | 需要主动调查或与特定角色对话 |
| 核心隐藏条目 | 4分 | 需要深入调查、解锁身份卡隐藏层或破解核心诡计 |

**你的目标**：在死前尽可能多地收集信息条目。死亡时，你将立即结算已收集的全部信息得分。

### 2.3 死亡与终局

**除侦探右代宫战人与魔女贝阿朵莉切外，所有人都会死。**

- 死亡方式分为两种：
  1. **触发死亡**：当你的角色满足某些隐藏条件时自动死亡。
  2. **强制死亡**：贝阿朵莉切（GM）直接宣告你的角色死亡。

- 死亡后你将**结算得分**，之后可以旁观游戏，但不能再收集新信息。

- 侦探**战人不会死亡**，他的得分在最终结局时结算。

- **最终对决**：第七天，若战人仍存活，他将与贝阿朵莉切进行最终对决——解释岛上发生的一切。根据战人的推理，游戏将进入不同结局。

### 2.4 调查与行动

**每日流程**：
1. **早晨**：发现新的尸体或事件（如果有）。
2. **调查阶段**：GM将所有人分成2-3组，每组前往不同地点调查。
3. **自由交流**：调查后，有一段自由交流时间，可以与其他玩家对话、交换信息。
4. **夜晚**：某些事件可能在夜间发生。

**你可以进行的行动**：
- **调查地点**：搜索某个区域，GM会根据你的搜索方式发放信息条目。
- **对话**：与其他角色交谈。注意：对方可能说谎。
- **验尸**（仅限战人）：战人可以检查尸体，获得额外线索。
- **使用道具**：如果你持有某件物品，可以在适当时机使用（需告知GM）。
- **向贝阿朵提问**：每位玩家每天可以向贝阿朵（GM）提一个问题。贝阿朵**必须如实回答**，但她可能用魔法隐喻、红字陷阱或模糊话术来隐藏真相。

### 2.5 红字与金字

**红字**：贝阿朵可以说出"绝对真实"的红字真言。你可以要求GM对某个命题使用红字确认，但GM有权拒绝（每日限制）。红字本身可能带有陷阱，例如：
> 红字："这间房间里没有人类。" 
> *陷阱：房间里可能有魔女、幽灵或非人之物。*

**金字**：贝阿朵偶尔会用金字下达"绝对命令"。金字的内容绝对真实且无法违抗，但每次使用金字都会暴露一个对应等级的真相。

## 三、角色链与切换（角色切换版规则）

每位玩家（除战人外）控制一条**角色链**，链中角色按预定顺序死亡，玩家按顺序切换。

**切换触发条件**：
1. 链中当前角色死亡（最常见）。
2. 极少数情况下，GM可以通过"魔法仪式"强制玩家切换（需消耗一次GM击杀机会）。

**切换流程**：
1. GM宣告当前角色死亡，该角色玩家进行死亡结算（已收集信息得分+隐藏条目解锁得分）。
2. GM将下一环角色的身份卡交给该玩家——但**仅公开层可阅读**。半隐藏层与隐藏层由GM密封保管，玩家**不可查看**。
3. 玩家以新身份继续游戏，已收集信息全部保留，但对新角色的秘密一无所知。
4. 若链中所有角色均已死亡，该玩家正式出局，进入观剧模式。

**"失控"机制——NPC化强制行动**：
当玩家基于当前掌握的信息，**理论上无法做出合理决策**（因为关键动机/秘密被密封在隐藏层中），GM有权接管该角色并执行"NPC化强制行动"。

每次强制行动后，GM应向该玩家**私下说明**强制行动的原因（但不揭示具体隐藏条目内容）。

## 六、玩家须知

1. **不要偷看其他玩家的身份卡**。
2. **不要拆阅自己的核心隐藏层**，除非GM明确告知你可以开启。
3. **不要在游戏外讨论剧本内容**（若分多轮进行）。
4. **可以向GM提问**，但GM不一定直接回答。
5. **死亡不是结束**，你可以旁观到终局。
6. **享受扮演**，而非单纯追求胜利。

> *「没有爱，就看不见。」*
> *「愿你在六轩岛的迷雾中，找到属于你的真相。」*
