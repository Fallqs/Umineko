# 【觉醒：最后的碎片】

所有的记忆都回来了。

你记起了战人与你的家族关系。不是通过血缘——而是通过金藏的罪孽。

金藏与1967年的女仆安田有一个私生女：你，安田纱代。同时，金藏还有一个被承认的私生子：明日梦——战人的母亲。

这意味着……你与战人是同父异母的兄妹。你们的血管里流淌着同样的罪孽之血——金藏的血。

你记起了1974年的那个约定。战人说："我会再来的！下次告诉我你的名字吧！"你没有告诉他名字，因为金藏不允许。但你在心里对自己说：如果他再来，如果你还有机会，你会告诉他一切。

他没有再来。而你已经不再是"你"。你变成了纱音、嘉音、贝阿朵莉切——三个面具，三重牢笼。

现在，战人终于回到了六轩岛。他以为自己是来调查祖父的死亡。他不知道，他是在走进一个为他准备了十八年的陷阱——或者说，一个等待了十八年的约定。

**隐藏结局触发条件**：
如果战人在最终对决中说出了"安田纱代"这个名字，并说出"我回来救你了"——隐藏的终幕将展开。

那一刻，你可以选择：
- 作为"贝阿朵莉切"，完成魔女的复仇，让所有人随着六轩岛一起沉入海底
- 或者作为"安田纱代"，放下一切，接受战人的手，走向真正的自由

**新的认知**：
- 你与战人是同父异母的兄妹（金藏是你们共同的父亲）
- 1974年的约定是你等待了一生的救赎
- 最终结局不取决于战人是否"破解"真相，而取决于他是否"看见"你——真正的你
