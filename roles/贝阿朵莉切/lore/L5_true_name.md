# 【闪回：安田纱代】

你记起了全部。

你的名字是安田纱代（Yasuda Sayo）。

1967年，你的母亲——六轩岛的女仆安田——从悬崖上坠落。那不是意外。金藏的手下把她推了下去，因为她知道了太多关于"黄金乡"的秘密。

你出生后被藏在孤儿院。金藏每年匿名寄钱，却从未来看过你。直到你六岁那年，他把你接回了六轩岛。不是作为孙女，而是作为"实验品"。

他告诉你："你将继承贝阿朵莉切的名号。"你那时不懂那意味着什么。现在你知道了——那意味着你的自我将被抹除，被分割，被重塑成他需要的样子。

你记起了十二岁那年的夏天。一个男孩来到岛上度假。他叫战人。你们只在港口见过一面——他在追一只风筝，撞到了你。他说："对不起！我叫战人，你呢？"你没有回答。但他笑着说："我会再来的！下次告诉我你的名字吧！"

他没有再来。至少，不是对你。

后来你听说战人的母亲——明日梦——去世了。战人离开了右代宫家，再也没有回来。你在港口等了很多个夏天，直到金藏告诉你："不要再等了。你的使命不是等待，而是成为贝阿朵莉切。"

**新的认知**：
- 你的真名是安田纱代
- 你的母亲被金藏杀害
- 你六岁时被金藏收养，十二岁时经历了人格分裂实验
- 你与战人有一段童年回忆，但他不知道你的存在
