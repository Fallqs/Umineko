# 【闪回：镜中的真相】

你站在碎裂的镜子前，终于看清了自己的脸。

那不是魔女的容颜。那是一个年轻女性的脸——苍白、消瘦、带着长期服药留下的痕迹。

纱音、嘉音、贝阿朵莉切……你们不是三个人。你们是**同一个人**。

安田纱代。那是你的真名。或者曾经是。

金藏找到你时，你只是一个在孤儿院长大的孩子。他把你带到六轩岛，不是因为善心，而是因为你继承了他的血脉——你是他的孙女，是他与1967年那个坠崖女仆的孩子。

他不能承认你的存在，因为那将暴露他的丑闻。所以他选择了一个更"优雅"的解决方案：把真实的你藏起来，创造出三个虚构的"你"来代替。

纱音是他的"理想孙女"——温顺、勤劳、永远不会质疑。嘉音是他的"理想继承人"——沉默、可靠、永远不会要求权利。而贝阿朵莉切……你是他的"理想魔女"——强大、神秘、永远不会死去。

薛定谔规则的本质终于清晰了：纱音和嘉音不能同时出现在第三人面前，因为**一个人不可能同时以两个身体存在**。他们只是你的两面，是你的面具。
